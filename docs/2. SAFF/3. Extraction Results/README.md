# Extraction Results

This section documents the parsed and processed artifacts generated from SAFF specification PDFs, particularly the GESB SuperStream Payroll Data Specification.

## Overview

These are the structured outputs from parsing SAFF specification PDFs. Each artifact represents a different aspect of the extracted content and can be used for different purposes.

## GESB Specification Artifacts

### 1. Dependency Trace
**File**: `superstream-payroll-data-specification.dependency-trace.json`  
**Location**: `knowledge_base/processed/structured-business-file-formats/saff/specifications/gesb/`

**Purpose**: Document structural analysis showing page-level dependencies and content relationships

**Content Structure**:
```json
{
  "document": "GESB SAFF Specification",
  "pages": [
    {
      "page_num": 1,
      "content_type": "cover",
      "dependencies": [...],
      "references": [...]
    }
  ]
}
```

**Use Cases**:
- Understanding document structure
- Tracing content dependencies
- Identifying related sections
- Navigation and cross-referencing

**Generated By**: Dependency analysis phase of extraction

### 2. PyMuPDF Table Analysis
**File**: `superstream-payroll-data-specification.pymupdf-tables.json`  
**Location**: `knowledge_base/processed/structured-business-file-formats/saff/specifications/gesb/`

**Purpose**: Detailed metadata about tables extracted using PyMuPDF word layer

**Content Structure**:
```json
{
  "document": "GESB SAFF Specification",
  "tables": [
    {
      "table_id": "table_001",
      "page": 5,
      "location": {"x": 50, "y": 100, "width": 500, "height": 200},
      "columns": 4,
      "rows": 12,
      "headers": ["Field", "Type", "Length", "Required"],
      "extraction_quality": 0.92,
      "notes": "..."
    }
  ]
}
```

**Content**:
- Table boundaries (coordinates)
- Column structure and headers
- Row counts
- Extraction quality metrics
- Known issues per table
- Cross-reference information

**Use Cases**:
- Understanding table structures
- Debugging extraction issues
- Quality assessment
- Schema inference
- Test case selection

**Generated By**: PyMuPDF table detection and analysis

## Using These Artifacts

### For Development
```python
import json

# Load table metadata
with open('superstream-payroll-data-specification.pymupdf-tables.json') as f:
    tables = json.load(f)

# Find tables with extraction quality > 90%
high_quality = [t for t in tables['tables'] if t['extraction_quality'] > 0.9]
```

### For Quality Assessment
1. Check `extraction_quality` scores in PyMuPDF table analysis
2. Review `notes` field for known issues
3. Compare against dependency trace for structure validation

### For Test Case Selection
```python
# Find most complex tables for testing
complex_tables = sorted(
    tables['tables'],
    key=lambda t: (t['columns'] * t['rows']),
    reverse=True
)[:5]
```

## Known Limitations

1. **Table Detection**: Some tables may be missed if they use unusual formatting
2. **Merged Cells**: Not all merged cells are correctly reconstructed
3. **Multi-level Headers**: Complex header structures may not be fully captured
4. **Special Content**: Some special formatting (rotated text, etc.) may be lost
5. **Overlapping Content**: Boundaries may not be perfect for overlapping elements

See [Quality Issues](../2.%20Implementation/table-parsing/quality-issues.md) for more details.
